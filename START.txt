ЛУНА · 2.5.0

Нужны Node.js 22+, Python 3.11+ и Xcode с iOS Simulator.
Откройте распакованную папку luna в VS Code. Команды запускайте из неё.

ДООБУЧЕНИЕ QWEN3-8B

В этой версии есть код настоящего обучения и подключения весов к приложению.
Архив не содержит обученных весов: вычисления запускаются на вашем компьютере.
Используется 4-битная базовая модель и LoRA: оптимизатор изменяет дополнительные
параметры выбранных слоёв. Исходные 8,2 млрд параметров остаются замороженными.
Это дообучение большой модели, а не её обучение с нуля.

Нужен Mac с Apple Silicon, от 16 ГБ памяти; предпочтительно 24 ГБ и больше.
Оставьте минимум 40 ГБ свободного места для скачивания и преобразования весов.
Это ориентиры, а не гарантия достаточной памяти. Закройте Ollama, симулятор и другие
тяжёлые приложения во время обучения. Подключите питание и отключите сон Mac.

Выполните по очереди из папки luna, дожидаясь завершения каждой команды:
   npm run ai:doctor
   npm run ai:prepare-model
   npm run ai:train
   npm run ai:evaluate
   npm run ai:serve

ai:prepare-model скачивает официальную Qwen/Qwen3-8B и делает локальную 4-битную копию.
ai:train запускает 240 итераций, 60 обновлений оптимизатора; обучение может быть долгим.
При нехватке памяти можно начать новый запуск: npm run ai:train -- --layers 2
Если папка backend/models/luna-lora уже создана, укажите новую через --output.
Не удаляйте прежние веса ради повторного эксперимента. Каждый запуск начинает
обучение заново; автоматического восстановления состояния оптимизатора нет.

Обученные веса: backend/models/luna-lora/adapters.safetensors.
training_report.json содержит число обновлений и величину изменения параметров.
losses.json содержит ошибки обучения; evaluation.json — ответы до и после обучения.
Проверка сравнивает JSON, ссылки на источники, язык и ограничения ответа на отложенных
примерах. Она не проверяет медицинскую правильность. Если проверка не пройдена,
новые веса не подключаются. Прочитайте ответы в evaluation.json перед демонстрацией.

Стартовый набор: 265 примеров (25 русских и 240 английских), 134 источника.
Обучение — 224, проверка — 23, тест — 18. Источники между выборками не пересекаются.
Это небольшой экспериментальный набор, а не клинически проверенный медицинский датасет.
Источники: открытые справки MedlinePlus и русские карточки из базы приложения.
Контексты анализов синтетические; личные дневники, переписка и анализы не используются.
Обновить подготовленный набор после изменения справок: npm run ai:data.
Обновлённый набор требует нового обучения; подменять тест старой модели нельзя.

После ai:serve оставьте терминал открытым. В другом терминале: npm ci, затем npm run ios.
В настройках помощника укажите http://127.0.0.1:8001 и проверьте подключение.
Проверка должна показать Qwen3-8B с дообучением «Луна». Модель работает на Mac,
а приложение на телефоне обращается к серверу. Для генерации через MLX Ollama не нужна.
Данные дневника и анализов добавляются к вопросу только с отдельного разрешения.
Если используете другой адаптер, задайте полный LUNA_ADAPTER_PATH в backend/.env,
а ai:evaluate запускайте с --adapter и тем же путём.

БЫСТРЫЙ ЗАПУСК С ИСХОДНОЙ МОДЕЛЬЮ OLLAMA

Этот режим доступен отдельно, если обучение ещё не завершено.

1. Установка зависимостей приложения:
   npm ci

2. Откройте Ollama на Mac. Один раз скачайте модель:
   ollama pull qwen3:4b

3. В отдельном терминале запустите сервер и оставьте его работать:
   npm run backend
   Скрипт сам создаёт Python-окружение, устанавливает зависимости и строит индекс.
   Адрес для симулятора на этом Mac: http://127.0.0.1:8001

4. В другом терминале запустите приложение:
   npm run ios
   После первого успешного запуска для изменений TypeScript достаточно npm start.

5. В помощнике откройте настройки → «Проверить подключение».
   Проверка показывает состояние сервера и наличие модели в Ollama.
   Первый ответ после загрузки модели может занять больше времени.

6. Добавьте свои результаты в «Анализы»: значение, единицы и референс из бланка.
   Нажмите «Обсудить анализы с ИИ», разрешите доступ и отправьте вопрос.
   Доступ к дневнику включается отдельно. Демо-примеры и вложения не передаются.
   PDF и фотографии не распознаются автоматически: значения нужно внести вручную.

Если порт 8001 занят, остановите прежний сервер через Ctrl+C в его терминале.
Либо запустите LUNA_PORT=8002 npm run backend и смените порт в настройках помощника.

Для физического iPhone: Mac и телефон должны быть в одной доверенной сети.
Скопируйте backend/.env.example в backend/.env и задайте длинный случайный LUNA_API_TOKEN.
Запустите LUNA_HOST=0.0.0.0 npm run backend. В приложении укажите адрес Mac и этот ключ.
127.0.0.1 на телефоне указывает на телефон, а не на Mac. Публичный сервер требует HTTPS.

Необязательно — поиск по смыслу:
   ollama pull qwen3-embedding:0.6b
   npm run rag:index
Без этого работает текстовый поиск. Построение векторов возобновляется из кэша.
Обновить официальные материалы MedlinePlus: npm run rag:update
После обновления материалов векторный индекс нужно построить заново.

Проверки: npm run typecheck; npm test; npm run rag:check -- --lexical
Python-тесты: установите backend/requirements-dev.txt и запустите pytest из backend.

Приложение: src/screens — экраны, src/domain — расчёты, src/features — функции.
Помощник: backend/app/service.py — запросы, lab_analysis.py — сравнение анализов,
diary.py — сводка дневника, knowledge.py — поиск. Источники: backend/knowledge.

Это прототип с локальной моделью и RAG, без подключения к ЕМИАС.
Улучшение медицинских ответов после дообучения пока не подтверждено.
Источник каждого материала, дата и сведения о повторном использовании сохранены в JSON.
Сводка не устанавливает диагноз, причину задержки и эффект препарата. Клинической
валидации не было. Изменение числа не означает улучшение или ухудшение здоровья.
При недоступной модели показывается расчёт и справка; это явно помечается в ответе.
Дневник хранится на устройстве; чат не сохраняется после перезапуска. Разрешённые
данные обрабатываются сервером и локальной моделью. Полного шифрования хранилища,
учётных записей и инфраструктуры для медицинского сервиса в прототипе нет.

При обновлении сохранены идентификатор приложения и формат старых записей.
Не удаляйте установленное приложение и не нажимайте «Удалить данные», если хотите
сохранить дневник. Обучение полной Qwen3-8B, её ответы и сборка в Xcode проверяются на вашем Mac.
