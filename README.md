Луна 🌙

Мобильный прототип для наблюдения за менструальным циклом. Объединяет дневник самочувствия, записи о лекарствах, анализы и ИИ-помощника в одном приложении.

Возможности

 ● Календарь: начало и окончание месячных, день цикла и прогноз следующей менструации.
 ● Дневник: симптомы, интенсивность и заметки по датам.
 ● Препараты: 13 вариантов с поиском, ручной ввод других средств, даты приёма.
 ● Анализы и справки: ручное добавление данных и медицинских документов.
 ● ИИ-помощник: ответы с источниками, сопоставление дневника, приёма препаратов и результатов анализов.
 ● Уведомления: локальные напоминания; тестовые push-уведомления требуют настройки Expo/APNs.

Технологии

Приложение: React Native, Expo, TypeScript.
Сервер: Python, FastAPI, SQLite для поискового индекса.
ИИ: RAG — поиск по медицинским материалам перед ответом; локальная Qwen через Ollama или Qwen3-8B с LoRA-адаптером через MLX.

Запуск на Mac

Нужны Node.js, Python 3.11+ и Xcode с установленным iOS Simulator. Команды выполняются из корня проекта.

В первом терминале — приложение:

npm install

npm run ios

Во втором — сервер в справочном режиме, без генерации моделью:

LUNA_GENERATION_ENABLED=false npm run backend

В настройках помощника укажи http://127.0.0.1:8001 для iOS Simulator. На физическом телефоне нужен доступный по сети адрес Mac и настройка токена сервера.

Для дообученной модели на Mac с Apple Silicon используй вместо справочного сервера npm run ai:serve. Команда требует подготовленных базовых весов, обученного адаптера и успешно пройденной технической оценки. Веса не входят в репозиторий.
Данные и ограничения
Записи сохраняются на устройстве. Дневник и анализы передаются серверу помощника только при разрешённом доступе к соответствующему разделу.
Это прототип: интеграции с ЕМИАС и Госуслугами нет. Наличие препарата в списке не означает наличие медицинской справки о нём. ИИ не устанавливает диагноз и не доказывает, что лекарство вызвало изменение цикла. Техническая оценка модели не подтверждает медицинскую точность.
